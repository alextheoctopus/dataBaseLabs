
# customDB – Документация по интерфейсам и методам

Проект **customDB** реализует упрощённую локальную базу данных.  
Ниже описаны все ключевые интерфейсы: их назначение и методы.

---

## Интерфейс `Table`

**Назначение:**  
Представляет таблицу в базе данных.  
Отвечает за все операции над строками (insert, update, delete, scan).

**Методы:**
- `insert(row: Row): RowId` — вставка новой строки.
- `get(id: RowId): Row?` — поиск строки по id.
- `update(id: RowId, newValues: Map<String, Any?>): Boolean` — обновление строки.
- `upsert(row: Row): RowId` — вставка или обновление строки.
- `delete(id: RowId): Boolean` — логическое удаление (tombstone).
- `scan(predicate, sort, limit, offset): Cursor<Row>` — выборка строк по условию.
- `countApprox(): Long` — приблизительное количество строк.
- `compact()` — очистка удалённых записей и перепаковка файла.
- `close()` — освобождение ресурсов.

---

## Интерфейс `StorageEngine`

**Назначение:**  
Движок базы данных. Управляет таблицами как файлами: создание, открытие, удаление.

**Методы:**
- `createTable(schema: TableSchema): Table` — создать таблицу.
- `openTable(name: String): Table` — открыть таблицу.
- `dropTable(name: String): Boolean` — удалить таблицу.
- `listTables(): List<String>` — список всех таблиц.
- `close()` — закрыть движок.

---

## Интерфейс `Index`

**Назначение:**  
Индекс ускоряет поиск строк по определённым полям (как в SQL `CREATE INDEX`).  
Например, индекс по `username` позволяет быстро искать `WHERE username = 'Alice'`.

**Поля:**
- `name` — имя индекса.
- `table` — имя таблицы.
- `fields` — список полей, по которым построен индекс.
- `unique` — уникален ли индекс.

**Методы:**
- `upsert(rowId, values, physicalRef)` — зарегистрировать или обновить запись в индексе.
- `remove(rowId)` — удалить строку из индекса.
- `findExact(lookup)` — поиск по точному совпадению.
- `range(field, from, to, inclusive)` — поиск по диапазону.
- `close()` — закрыть индекс.

---

## Интерфейс `RecordCodec`

**Назначение:**  
Отвечает за сериализацию данных строки (`values`) в байты и обратно.  
Формат может быть JSON, BSON, CBOR, Protobuf и т.д.

**Методы:**
- `encode(values): ByteArray` — кодирование Map в байты.
- `decode(bytes): Map<String, Any?>` — декодирование байтов обратно в Map.

---

## Интерфейс `RecordFormat`

**Назначение:**  
Определяет, как запись хранится в файле (структура: tombstone, id, длина, payload).

**Методы:**
- `append(tombstone, id, payload): Long` — записать новую запись в конец файла.
- `readAt(offset): Record` — прочитать запись по смещению.
- `markDeleted(offset)` — пометить запись как удалённую.

**Вложенный класс:**
```kotlin
data class Record(
    val tombstone: Boolean,
    val id: RowId,
    val payload: ByteArray
)
```
- `tombstone` — удалена или жива,
- `id` — уникальный идентификатор строки,
- `payload` — данные строки в байтах.

---

## Интерфейс `Cursor<T>`

**Назначение:**  
Позволяет итерироваться по результатам запроса, не загружая всё в память.  
Аналог `ResultSet` в JDBC.

**Методы:**
- `hasNext()` (унаследован от `Iterator`) — есть ли следующая строка.
- `next()` (унаследован от `Iterator`) — вернуть строку.
- `close()` — закрыть курсор (освободить файл/ресурсы).

---

## Интерфейс `Row`

**Назначение:**  
Представляет одну строку таблицы.

**Поля:**
- `id: RowId` — уникальный идентификатор строки.
- `values: Map<String, Any?>` — набор полей и их значений.

---

## Интерфейс `TableSchema`

**Назначение:**  
Определяет структуру таблицы (какие поля и какие типы у них).

**Поля:**
- `name: String` — имя таблицы.
- `columns: List<Column>` — список колонок.

**Вложенный класс:**
```kotlin
data class Column(
    val name: String,
    val type: FieldType
)
```

---

## Интерфейс `Predicate`

**Назначение:**  
Фильтр для строк в методе `scan`.  
Определяет, подходит ли строка под условие.

**Метод:**
- `fun test(row: Row): Boolean` — проверяет строку.

---

## Интерфейс `Sort`

**Назначение:**  
Определяет порядок сортировки в `scan`.

**Поля:**
- `orders: List<Order>` — список правил сортировки.

**Вложенный класс:**
```kotlin
data class Order(
    val field: String,
    val asc: Boolean = true
)
```
