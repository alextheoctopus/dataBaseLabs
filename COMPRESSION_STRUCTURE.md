# Структура реализации сжатия

## Где что находится

### ✅ Самостоятельная реализация алгоритма сжатия

**Файл:** `app/src/main/kotlin/com/customDB/compression/LZ77.kt`

**Что делает:**
- Это **наша собственная реализация** алгоритма LZ77
- Ищет повторяющиеся последовательности в данных
- Заменяет их ссылками (offset, length)
- Работает полностью самостоятельно, без использования готовых библиотек

**Как работает:**
1. Проходит по данным байт за байтом
2. Для каждой позиции ищет самое длинное совпадение в предыдущих данных (окно 32KB)
3. Если находит совпадение ≥ 3 байт → создает ссылку (Reference)
4. Если не находит → записывает байт как есть (Literal)
5. Результат: список токенов (Literal или Reference)

**Пример:**
```
Входные данные: "ABCABCABC"
LZ77 результат:
  - Token.Literal('A')
  - Token.Literal('B') 
  - Token.Literal('C')
  - Token.Reference(offset=3, length=6)  // ссылка на "ABCABC"
```

---

### ⚠️ Использует готовые библиотеки (для совместимости с gunzip)

**Файл:** `app/src/main/kotlin/com/customDB/compression/GzipFormat.kt`

**Что делает:**
- Использует **готовый** `java.util.zip.GZIPOutputStream` для создания GZIP файла
- Использует **готовый** `java.util.zip.GZIPInputStream` для распаковки
- Это нужно для совместимости с gunzip

**Проблема:** Это не "самостоятельная реализация", а обертка над готовой библиотекой.

---

### ❌ Не используется сейчас

**Файл:** `app/src/main/kotlin/com/customDB/compression/DeflateEncoder.kt`

**Что делает:**
- Должен был кодировать токены LZ77 в DEFLATE формат
- Сейчас использует готовый `java.util.zip.Deflater`
- **Не используется** в GzipFormat (там используется GZIPOutputStream напрямую)

---

## Текущая архитектура

```
Данные → LZ77.compress() → токены (наша реализация)
       ↓
       GzipFormat.compress() → использует GZIPOutputStream (готовое)
       ↓
       GZIP файл (совместим с gunzip)
```

**Проблема:** LZ77 используется только для сравнения, но не для создания финального GZIP файла.

---

## Что нужно для полной самостоятельной реализации

Чтобы полностью самостоятельно реализовать GZIP формат, нужно:

1. **Реализовать DEFLATE кодирование** (вместо использования Deflater):
   - Преобразовать токены LZ77 в бинарный DEFLATE формат
   - Правильная структура блоков (BFINAL, BTYPE)
   - Huffman кодирование (опционально, но улучшает сжатие)

2. **Реализовать GZIP заголовок и footer**:
   - Magic numbers (0x1F, 0x8B)
   - Метод сжатия (DEFLATE = 8)
   - CRC32 вычисление
   - Размер исходных данных

3. **Собрать все вместе:**
   - Заголовок GZIP
   - DEFLATE данные (из нашего LZ77)
   - CRC32
   - Размер
